📦 Sistema de Controle de Estoque






🎓 Projeto acadêmico desenvolvido para a disciplina de Programação de Computadores da Universidade Positivo.

📋 Sobre o projeto

O Sistema de Controle de Estoque é uma aplicação desenvolvida em Python com o objetivo de facilitar o gerenciamento e a organização de produtos em estoque.

O projeto foi desenvolvido como atividade acadêmica, buscando aplicar na prática os principais conceitos de programação estudados durante a disciplina.

A aplicação permite trabalhar com o gerenciamento de informações relacionadas aos produtos, proporcionando uma solução simples, organizada e funcional para o controle de estoque.

🚀 Funcionalidades
📦 Gerenciamento de produtos
➕ Cadastro de produtos
🔎 Consulta de informações
✏️ Atualização de dados
🗑️ Remoção de produtos
📊 Controle de quantidade em estoque
🗂️ Organização das informações
