# Sistema de Gestão de Estoque 📦

## Objetivo
Sistema desenvolvido em Python para simular a gestão de um estoque
básico de produtos, permitindo ao usuário visualizar, registrar
entradas e saídas de produtos por meio de um menu interativo no terminal.

## Tecnologias
- Python 3.14
- Estruturas de dados — dicionários de dicionários
- Controle de fluxo — while, if/elif/else
- Boas práticas PEP 8 e comentários de código

## O que aprendi
- Manipulação de dicionários aninhados para representar dados reais
- Criação de menus interativos com laço while
- Validações de negócio com condicionais aninhadas
- Tratamento de entradas inválidas com fallback
- Importância de validar quantidade positiva antes de modificar dados
